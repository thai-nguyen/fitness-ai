## Core MVP (committed P0 direction)

Aligned with AUTH-001 / AUTH-002:

- Authentication (email / Apple / Google as product direction; provider selection still pending)
- Password recovery where applicable; account deletion and data management
- User onboarding (profile, age, height, weight, goals, experience, equipment, availability, limitations)
- Approved exercise catalog (target 50–100; licensing + expert review **pending**)
- Personalized training plans, schedules/rest days, substitutions, rescheduling
- Immutable training plan versions; user confirmation for activation / material adjustments
- Workout execution (sets/reps/weights/rest timer), history, local persistence, resume, synchronization
- Conversational AI Coach, structured persistent memory with user controls, recommendation cards
- Basic adaptive coaching suggestions; pre/post-workout coaching; feedback (difficulty/soreness)
- Basic progress and weight tracking
- Reminders / notification preferences
- Privacy-safe product analytics; minimal administration
- Security, consent, privacy and AI safety / evaluation

Supported fitness goals: muscle building, strength improvement, general fitness, **basic weight loss**.

## Explicitly deferred

- Running / marathon / endurance training
- Advanced nutrition recognition / full nutrition module
- Social fitness features
- Wearable / health integrations (production)
- Production subscription payments / commercial billing
- Advanced adaptation / recovery suite / proactive coach (V1.5+)

## Long-term vision (non-MVP)

Premium AI personal fitness coach connecting training, nutrition, recovery, progress and eventually community/endurance. Inspiration quality bars (Zing Coach / Cal AI / Strava) with independent brand. Vision does not authorize speculative Phase 0 feature work.
