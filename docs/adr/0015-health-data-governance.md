# ADR-0015 — Health-Adjacent Data Governance

| Field | Value |
| --- | --- |
| Status | `PROPOSED` |
| Date | 2026-11-25 |

## Decision

Classify health-adjacent data; minimize collection; no raw health/chat in analytics/logs; consent versioning; account deletion includes memory/media/derived data. Jurisdiction/legal basis **pending**. Synthetic data only until governance approval.

## Validation

PH00-M08 threat model + provider assessment.
