# Change Requests

Use a Change Request when a material change is necessary relative to approved product scope, technical direction, or deferred-technology policy.

## Required fields

1. Current decision
2. Proposed change
3. Technical rationale
4. Product impact
5. Effort impact
6. Risks
7. Alternatives
8. Required approval

## Naming

`CR-YYYYMMDD-short-title.md`
