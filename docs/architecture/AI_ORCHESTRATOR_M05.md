# AI Orchestrator (PH00-M05)

Lightweight single-path orchestration in `CoachOrchestrator`:

1. Trusted synthetic user scope (`synth_*`)
2. Deterministic safety/injection gate
3. Intent resolution (deterministic)
4. Memory / hybrid generation / chat
5. Independent M04 validation for plans
6. Allowlisted recommendation cards

No multi-agent loops. No unrestricted tools. LLM cannot mutate DB or activate plans.
